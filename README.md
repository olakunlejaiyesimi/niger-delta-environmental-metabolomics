# Niger Delta Environmental Metabolomics

This repository contains R scripts and supporting analytical resources for a metabolomics study investigating differences in the chemical profiles of vegetation and wild-caught flies collected from communities in the Niger Delta region of Nigeria and reference locations.

## Study Overview

The study uses untargeted LC-MS metabolomics to investigate metabolic differences associated with environmental conditions in the Niger Delta, with particular interest in petroleum-related pollution.

The biological samples include cassava, plantain, waterleaf, and wild-caught flies. Reference vegetation samples were collected from Ibadan, while reference fly samples were collected from Ibadan and Port Harcourt.

## Repository Contents

- `scripts/` — R scripts for statistical analyses and figure generation.
- `data/` — Processed LC-MS metabolomics datasets.
- `metadata/` — Sample information and sampling locations.
- `config/` — Analysis parameters and software requirements.

## Statistical Analysis

The R scripts support comparative metabolomics analyses, including statistical testing, multiple-testing correction, metabolite detection comparisons, and visualization of metabolic differences.

## Raw LC-MS Data Availability

Raw LC-MS data are deposited in the MassIVE repository under accession **MSV000103910** (DOI: https://doi.org/10.25345/C5J960R0Q).

The dataset includes positive- and negative-ionization mzML files, sample metadata, and acquisition documentation. The dataset is currently private pending public release.

Processed metabolomics datasets and R analysis scripts are provided in this GitHub repository.

## Sample Metadata

The `sample_metadata.csv` file contains specimen-level metadata shared by both positive- and negative-ionization LC-MS datasets. Although the `mode` column is labelled `NEG`, the same biological specimens were analysed in both ionization modes. Accordingly, the R scripts match samples using specimen identifiers without filtering the metadata by ionization mode.

## Metabolite Annotation

The file `highlighted_small_molecules_final_OJ_10.12.2026.csv` contains the metabolite annotation information used as an input to the primary statistical analysis script (`Niger_Delta_RStudio_Analysis_v2_0.R`).

The file `complete_v2_feature_statistics_annotated.csv` contains the statistical analysis outputs together with additional proposed metabolite annotations curated during manuscript preparation.

These annotations are putative unless supported by appropriate confirmatory evidence.

## Reproducibility

The analysis scripts are provided to support transparency and reproducibility. Detailed instructions, required input files, and software dependencies will be documented as the repository is finalized.

## Running the R Scripts

The R scripts were developed and executed in RStudio using the original positive- and negative-ionization LC-MS feature matrices, sample metadata, and annotated feature statistics.

To reproduce the analyses:

1. Download the repository from GitHub using **Code → Download ZIP**.
2. Extract the files to a local directory.
3. Copy the CSV files from `data/` and `metadata/` into the same directory as the R scripts.
4. Open RStudio and set the working directory to the folder containing the scripts and input CSV files.
5. Install the required R packages as indicated at the beginning of each script.
6. Execute the relevant scripts using `source("script_name.R")`, replacing `script_name.R` with the actual filename.

The file `complete_v2_feature_statistics_annotated.csv` contains statistical results generated by the primary analysis workflow, together with subsequently curated proposed metabolite annotations.

The same specimen-level metadata are used for both positive- and negative-ionization datasets. The `mode` column in the metadata does not restrict sample matching to negative-ionization data.

The analyses are exploratory and do not explicitly adjust for potential dependence among samples collected from the same sampling communities.

## MZmine Processing Workflows

The positive- and negative-ionization LC-MS datasets were processed using **MZmine version 4.50**.

The MZmine batch files documenting the processing workflows and associated parameters are available in the [`mzmine/`](mzmine/) directory.

These batch files can be used with the raw LC-MS data deposited in MassIVE (**MSV000103910**) to reproduce the feature-processing workflows, subject to updating local file paths and output directories.

The resulting processed feature matrices, curated metabolite annotations, and R analysis scripts are provided in the `data/` and `scripts/` directories.
